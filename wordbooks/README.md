## 📥 如何在 WordBar 客户端中导入自定义词库包？

1. 下载本目录中你需要的任意 `.json` 词库文件；
2. 打开 WordBar 软件，点击左下角的 **图书图标 📖** 呼出词库管理弹窗；
3. 点击右上角 **「+ 导入词库 / 卡片」** 按钮；
4. 选择 **「文件导入」**，将下载的 `.json` 文件拖入或点击上传；
5. 点击 **「确认导入」**，即可将全新词库加入你的背诵清单！
