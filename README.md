# 🌟 WordBar - Windows 任务栏吸附式沉浸背单词软件

WordBar 是一款专为 Windows 用户量身打造的**极简轻量、高效互动、吸附在任务栏正上方**的桌面级背单词神器。支持全透明底色、四选一抢答互动、真人发音、连击激励、海量内置词库以及自定义单词卡片/词典导入。

---

## ✨ 核心特性

### 1. 📌 精准吸附与极致置顶 (Docked & Always on Top)
- **智能计算位置**：自动获取 Windows 工作区（WorkArea）并精确贴合在任务栏正上方，宽度自适应全屏或可拖动调整。
- **全系统顶层置顶**：无论在写代码、浏览网页、看文档还是打字，WordBar 始终静默陪伴在视线边缘。
- **一键复位**：如果拖拽移动过，点击左侧图钉 📌 即可瞬间归位吸附到任务栏上方。

### 2. 🎨 透明 / 毛玻璃 / 自由变色主题 (Theming & Opacity)
- **0% ~ 100% 自由透明度滑块**：真正做到背景全透明，仅文字悬浮，或开启现代磨砂毛玻璃（Backdrop Blur）。
- **丰富预设风格**：
  - **经典翠绿**：活力满满，成就感拉满。
  - **磨砂半透 (Glassmorphism)**：高透轻奢质感，完美融合任何壁纸。
  - **极简深黑**：深色护眼，夜间与开发人员首选。
  - **摸鱼极隐模式 (Stealth Mode)**：超低透明度与弱对比度，办公室摸鱼神器。
  - **柔和米纸**：温暖护眼色调。
  - **自定义调色盘**：支持通过取色器或 HEX 自由调节背景色与文字色。

### 3. 🎮 闯关式互动答题与高效学习 (Quiz Mode)
- **四选一抢答模式**：
  - 点击“手柄”图标或快捷键触发，底栏平滑扩展出 4 个选项卡。
  - 自动从词库智能生成 3 个干扰混淆释义。
  - 快捷键 `1 / 2 / 3 / 4` 盲操答题。
  - 答对触发清脆奖励和弦音效，答错标记并重现正确释义。
- **火焰连击系统 (Streak 🔥)**：连续答对累加连击次数，5 连击、10 连击触发专属庆祝音效！
- **摸鱼防窥模式**：支持关闭常显释义，鼠标悬浮或按空格键时才浮现释义，防止同事/主管窥屏。
- **自动轮播 (Auto-play)**：开启后每隔 6 秒自动切换下一词，潜移默化完成记忆。
- **真人发音 (TTS)**：标准美音/英音双引擎发音，支持按 `P` 键即时朗读，亦可开启切词自动朗读。

### 4. 📚 开箱即用内置词库 & 强大导入功能
- **内置官方精编词库**：
  - 大学英语四级核心词汇 (CET-4)
  - 大学英语六级进阶词汇 (CET-6)
  - 考研英语必考核心高频词
  - 托福 / 雅思学术高分必背词
  - 程序员与职场高频商务词汇
- **导入自定义单词卡片 / 词典**：
  - 支持 **CSV / TSV / TXT** 文件及纯文本直接粘贴。
  - 智能分列识别（支持 `单词, 音标, 释义`、`单词 \t 释义`、`单词: 释义` 等）。
  - 支持 **JSON** 格式词典批量导入。
  - 导入前提供**实时数据表格预览**，即时统计词数。

## ⌨️ 快捷键指南

| 快捷键 | 功能说明 |
| :--- | :--- |
| `←` / `→` | 切换上一个 / 下一个单词 |
| `↑` (上箭头) | 标记为已掌握（熟词） |
| `↓` (下箭头) | 标记为生疏（重点复习） |
| `Space` (空格键) | 显隐当前单词中文释义 (摸鱼防窥) |
| `1` / `2` / `3` / `4` | 抢答模式下的选项选择 |
| `P` | 单词原声发音朗读 |
| `Esc` | 退出答题模式 / 关闭设置或词库窗口 |
| `Ctrl + Alt + H` | **全局老板键**：瞬间隐藏/呼出 WordBar |

## 🚀 启动与构建

### 1. 快速启动 (开箱即用)
- 双击根目录下的 `WordBar.exe`（或 `启动WordBar(静默无黑框).vbs`）。

### 2. 开发者安装与调试
```bash
# 1. 克隆代码仓库
git clone <your-repo-url>
cd words

# 2. 安装依赖
npm install

# 3. 本地构建
npm run build

# 4. 启动应用
npm start
```

### 3. 开发热重载模式
```bash
npm run dev
```
